# 第 3 章 線形回帰（Python 版）

原著第 3 章「Drawing a line close to our points」を Python で実装します。部屋数から住宅価格を予測する 1 次元の線形回帰を、**simple / absolute / square の 3 つのトリック** で学習します。

サンプル実装は `apps/grokking-ml-python/src/grokking_ml/ch03_linear_regression.py` です。

> **Jupyter Notebook で試す**: この章の実験は [ch03.ipynb](notebooks/ch03.ipynb) にまとめてあります。実装本体を読み込んで動かすので、値を変えてその場で試せます。

## この章で作るもの

- 直線モデル `price = slope * rooms + intercept`
- 1 点の情報だけを使ってモデルを少し良くする「トリック」3 種類
- 誤差を測る RMSE（二乗平均平方根誤差）
- トリックを繰り返して直線を当てはめる学習ループ

原著のコードは NumPy と matplotlib を使いますが、本シリーズでは標準ライブラリだけで書きます。計算がすべてコード上に見えている状態を保つためです。

## データセット

原著と同じ 6 件の住宅データを使います。特徴量は部屋数、ラベルは価格です。

| 部屋数 | 価格 |
| ---: | ---: |
| 1 | 155 |
| 2 | 197 |
| 3 | 244 |
| 5 | 356 |
| 6 | 407 |
| 7 | 448 |

「部屋が 1 つ増えるごとにおよそ 50 上がる」という関係が見て取れます。学習の目標は、この 50（傾き）と、部屋 0 のときの価格である 100 前後（切片）を、データだけから見つけることです。

## モデル

モデルは傾きと切片の 2 つの数値です。学習の途中で何度も更新しますが、**書き換えるのではなく新しいモデルを返す** 設計にします。こうすると「あるトリックがモデルをどう変えたか」を式として読めます。

```python
@dataclass(frozen=True)
class Model:
    """1 次元の線形モデル price = slope * rooms + intercept。"""

    slope: float
    intercept: float

    def predict(self, rooms: float) -> float:
        return self.slope * rooms + self.intercept
```

`frozen=True` の dataclass は不変になり、`__eq__` も自動生成されるのでテストが書きやすくなります。

## トリック 1: 単純なトリック

最初のトリックは「予測が実際より低ければ直線を上げる、高ければ下げる」だけの素朴なものです。動かす量はランダムな微小値です。

```python
def simple_trick(model: Model, rooms: float, price: float, rng: random.Random) -> Model:
    """単純なトリック。予測の上下だけを見て、ランダムな微小量だけ動かす。"""
    step_slope = rng.random() * 0.1
    step_intercept = rng.random() * 0.1
    predicted = model.predict(rooms)
    if price > predicted:
        slope = model.slope + step_slope if rooms > 0 else model.slope - step_slope
        intercept = model.intercept + step_intercept
    else:
        slope = model.slope - step_slope if rooms > 0 else model.slope + step_slope
        intercept = model.intercept - step_intercept
    return Model(slope, intercept)
```

乱数生成器を引数で受け取っている点が重要です。グローバルな `random` を直接使うとテストで結果を固定できません。`random.Random(0)` を渡せば同じ挙動を再現できます。

このトリックは方向しか見ていないため、**遠い点も近い点も同じだけ動かします**。効率が悪く、収束も安定しません。

## トリック 2: 絶対トリック

次のトリックは、動かす量に **特徴量（部屋数）を掛けます**。部屋数が大きい点ほど傾きへの影響が大きい、という直感を式にしたものです。

```python
def absolute_trick(model: Model, rooms: float, price: float, learning_rate: float) -> Model:
    """絶対トリック。誤差の符号のみを使い、特徴量に比例した量だけ動かす。"""
    predicted = model.predict(rooms)
    sign = 1.0 if price > predicted else -1.0
    return Model(
        model.slope + sign * learning_rate * rooms,
        model.intercept + sign * learning_rate,
    )
```

`sign` を掛けることで、原著の 4 分岐（価格の上下 × 部屋数の正負）を 1 本の式にまとめています。誤差の **符号だけ** を使うので、これは絶対誤差の勾配降下法に対応します。

## トリック 3: 二乗トリック

最後のトリックは、動かす量に **誤差そのもの** を掛けます。予測が大きく外れている点ほど大きく動かす、という考え方です。

```python
def square_trick(model: Model, rooms: float, price: float, learning_rate: float) -> Model:
    """二乗トリック。誤差の大きさに比例した量だけ動かす（二乗誤差の勾配降下法）。"""
    error = price - model.predict(rooms)
    return Model(
        model.slope + learning_rate * rooms * error,
        model.intercept + learning_rate * error,
    )
```

これは二乗誤差 `(price - predict(rooms))²` を傾きと切片で偏微分した結果と一致します。つまり **二乗トリック＝二乗誤差に対する勾配降下法** です。3 つのトリックのうち、以降の章でも使い続けるのはこれです。

3 つのトリックの関係を整理すると次のようになります。

| トリック | 動かす量 | 対応する損失 |
| :--- | :--- | :--- |
| simple | ランダムな微小値 | なし（ヒューリスティック） |
| absolute | 学習率 × 特徴量 | 絶対誤差 |
| square | 学習率 × 特徴量 × 誤差 | 二乗誤差 |

## 誤差を測る

学習が進んでいるかを判断するために、モデル全体の誤差を測ります。RMSE は各点の誤差を二乗して平均し、平方根を取ったものです。

```python
def rmse(labels: Sequence[float], predictions: Sequence[float]) -> float:
    """二乗平均平方根誤差。"""
    n = len(labels)
    total = sum((label - prediction) ** 2 for label, prediction in zip(labels, predictions))
    return math.sqrt(total / n)


def model_rmse(model: Model, features: Sequence[float], labels: Sequence[float]) -> float:
    return rmse(labels, [model.predict(x) for x in features])
```

平方根を取るのは、誤差を **ラベルと同じ単位** に戻すためです。RMSE が 7 なら「平均しておよそ 7 くらい価格を外している」と読めます。

## 学習ループ

あとは「ランダムに 1 点選んでトリックを適用する」を繰り返すだけです。これが確率的勾配降下法（SGD）です。

```python
def linear_regression(
    features: Sequence[float],
    labels: Sequence[float],
    learning_rate: float = 0.01,
    epochs: int = 1000,
    seed: int = 0,
) -> tuple[Model, list[float]]:
    """確率的勾配降下法で線形回帰を学習し、モデルとエポックごとの RMSE を返す。"""
    rng = random.Random(seed)
    model = Model(rng.random(), rng.random())
    errors: list[float] = []
    for _ in range(epochs):
        errors.append(model_rmse(model, features, labels))
        i = rng.randrange(len(features))
        model = square_trick(model, features[i], labels[i], learning_rate)
    return model, errors
```

原著のコードは学習の途中経過を matplotlib で描画しますが、ここでは代わりに **エポックごとの RMSE をリストで返します**。プロットしたければ呼び出し側で描けますし、テストからは「誤差が減っているか」を数値で検証できます。

`seed` を引数にしていることで、実行するたびに同じ結果が得られます。機械学習のコードをテストするうえで、乱数を外から制御できる形にしておくことは重要です。

## 実行結果

```bash
cd apps/grokking-ml-python
uv run python -c "
from grokking_ml.ch03_linear_regression import linear_regression, model_rmse
features = [1, 2, 3, 5, 6, 7]
labels = [155, 197, 244, 356, 407, 448]
model, errors = linear_regression(features, labels)
print(model.slope, model.intercept, model_rmse(model, features, labels))
"
```

学習率 0.01、1000 エポックで次の結果になりました。

| 項目 | 値 |
| :--- | ---: |
| 傾き（slope） | 51.0443 |
| 切片（intercept） | 91.5945 |
| 学習後の RMSE | 7.4501 |
| 初期の RMSE | 315.77 |

初期状態では誤差が 315 ほどありましたが、1000 エポック後には 7.45 まで下がりました。部屋数 4 の家の価格は約 295.77 と予測されます。

真の関係（傾き 50、切片 100）にぴったりは一致しません。SGD は毎回 1 点しか見ないため、最後に選ばれた点の影響が残るためです。誤差ゼロを目指すのではなく、**十分に小さい誤差に落ち着く** ことを確認するのが正しい読み方です。

## テスト

トリックの計算は手で検算できるので、期待値を直接書けます。

```python
def test_square_trick_is_proportional_to_the_error():
    model = Model(50.0, 100.0)
    moved = square_trick(model, rooms=3.0, price=300.0, learning_rate=0.01)
    assert moved.slope == pytest.approx(51.5)
    assert moved.intercept == pytest.approx(100.5)
```

予測は `50 × 3 + 100 = 250`、誤差は `300 - 250 = 50` です。傾きは `50 + 0.01 × 3 × 50 = 51.5`、切片は `100 + 0.01 × 50 = 100.5` になります。

学習全体のテストは、乱数の影響があるため **範囲** で検証します。

```python
def test_linear_regression_fits_the_housing_dataset():
    model, errors = linear_regression(FEATURES, LABELS, learning_rate=0.01, epochs=1000, seed=0)
    assert model.slope == pytest.approx(50.0, abs=5.0)
    assert model.intercept == pytest.approx(100.0, abs=20.0)
    assert model_rmse(model, FEATURES, LABELS) < 15.0
    assert len(errors) == 1000
    assert errors[-1] < errors[0]
```

最後の `errors[-1] < errors[0]` が、学習が実際に進んだことの検証です。値そのものではなく **性質** をテストしています。

```bash

# 7 passed
```

## まとめ

- 線形回帰は「1 点を見てモデルを少し動かす」を繰り返すだけで学習できます。
- 二乗トリックは二乗誤差に対する勾配降下法そのものです。以降の章の土台になります。
- 乱数はグローバル状態ではなく引数として受け渡すと、テストで挙動を固定できます。
- 学習の可視化はプロットに頼らず、エポックごとの誤差を返せば数値で検証できます。
