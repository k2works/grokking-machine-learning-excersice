# 第 3 章 線形回帰（F# 版）

原著第 3 章「Drawing a line close to our points」を F# で実装します。部屋数から住宅価格を予測する 1 次元の線形回帰を、**simple / absolute / square の 3 つのトリック** で学習します。

サンプル実装は `apps/grokking-ml-fsharp/src/GrokkingMl/Ch03LinearRegression.fs` です。

> **Polyglot Notebook で試す**: この章の実験は [ch03.ipynb](notebooks/ch03.ipynb) にまとめてあります。実装本体を読み込んで動かすので、値を変えてその場で試せます。

## この章で作るもの

- 直線モデル `price = slope * rooms + intercept`
- 1 点の情報だけを使ってモデルを少し良くする「トリック」3 種類
- 誤差を測る RMSE（二乗平均平方根誤差）
- トリックを繰り返して直線を当てはめる学習ループ

F# 版では ML.NET を使わず、標準ライブラリだけで書きます。

## モデル

モデルはレコード型で表します。F# のレコードは既定で不変・構造的等価性を持つため、追加の記述なしにこの用途を満たします。

```fsharp
/// 1 次元の線形モデル price = slope * rooms + intercept。
type Model =
    { Slope: float
      Intercept: float }

/// モデルによる予測。
let predict (model: Model) (rooms: float) = model.Slope * rooms + model.Intercept
```

`predict` をメソッドではなく **モジュールの関数** として定義しているのが F# らしい点です。関数なので `List.map (predict model)` のように部分適用でき、そのまま高階関数へ渡せます。

## トリック 1: 単純なトリック

予測が実際より低ければ直線を上げ、高ければ下げます。

```fsharp
/// 単純なトリック。予測の上下だけを見て、ランダムな微小量だけ動かす。
let simpleTrick (rng: Random) (model: Model) (rooms: float) (price: float) =
    let stepSlope = rng.NextDouble() * 0.1
    let stepIntercept = rng.NextDouble() * 0.1
    let predicted = predict model rooms

    if price > predicted then
        { Slope = (if rooms > 0.0 then model.Slope + stepSlope else model.Slope - stepSlope)
          Intercept = model.Intercept + stepIntercept }
    else
        { Slope = (if rooms > 0.0 then model.Slope - stepSlope else model.Slope + stepSlope)
          Intercept = model.Intercept - stepIntercept }
```

引数の順序に注目してください。**変わりにくいもの（乱数生成器）を先、変わりやすいもの（データ点）を後** に置いています。F# は左から部分適用できるため、この順序にしておくと `simpleTrick rng` という「乱数を固定したトリック」を作れます。

## トリック 2: 絶対トリック

同じ理由で、学習率を第 1 引数に置きます。

```fsharp
/// 絶対トリック。誤差の符号のみを使い、特徴量に比例した量だけ動かす。
let absoluteTrick (learningRate: float) (model: Model) (rooms: float) (price: float) =
    let sign = if price > predict model rooms then 1.0 else -1.0

    { Slope = model.Slope + sign * learningRate * rooms
      Intercept = model.Intercept + sign * learningRate }
```

`absoluteTrick 0.01` と部分適用すれば、学習率 0.01 を焼き付けた `Model -> float -> float -> Model` という関数が得られます。学習ループ側は「トリック」という関数値だけを受け取ればよく、ハイパーパラメータを知る必要がありません。

## トリック 3: 二乗トリック

```fsharp
/// 二乗トリック。誤差の大きさに比例した量だけ動かす（二乗誤差の勾配降下法）。
let squareTrick (learningRate: float) (model: Model) (rooms: float) (price: float) =
    let error = price - predict model rooms

    { Slope = model.Slope + learningRate * rooms * error
      Intercept = model.Intercept + learningRate * error }
```

これは二乗誤差の勾配降下法そのものです。以降の章で使い続けます。

| トリック | 動かす量 | 対応する損失 |
| :--- | :--- | :--- |
| simple | ランダムな微小値 | なし（ヒューリスティック） |
| absolute | 学習率 × 特徴量 | 絶対誤差 |
| square | 学習率 × 特徴量 × 誤差 | 二乗誤差 |

## 誤差を測る

RMSE はパイプライン演算子で「合計する → 平均する → 平方根を取る」という流れをそのまま書けます。

```fsharp
/// 二乗平均平方根誤差。
let rmse (labels: float list) (predictions: float list) =
    let n = float (List.length labels)

    List.zip labels predictions
    |> List.sumBy (fun (label, prediction) -> (label - prediction) ** 2.0)
    |> fun total -> sqrt (total / n)

/// モデルの RMSE。
let modelRmse (model: Model) (features: float list) (labels: float list) =
    rmse labels (features |> List.map (predict model))
```

`predict model` の部分適用がここで効いています。ラムダを書かずに `List.map (predict model)` と渡せます。

F# は暗黙の数値変換を行わないため、`List.length` の結果を `float` へ明示的に変換する必要があります。冗長に見えますが、意図しない整数除算を防いでくれます。

## 学習ループ

学習ループは `List.fold` で書きます。状態（モデルと誤差のリスト）を畳み込みながら更新していく形です。

```fsharp
/// 確率的勾配降下法で線形回帰を学習し、モデルとエポックごとの RMSE を返す。
let linearRegression (learningRate: float) (epochs: int) (seed: int) (features: float list) (labels: float list) =
    let rng = Random(seed)
    let initial = { Slope = rng.NextDouble(); Intercept = rng.NextDouble() }

    let step (model, errors) _ =
        let errors = modelRmse model features labels :: errors
        let i = rng.Next(List.length features)
        let model = squareTrick learningRate model features[i] labels[i]
        (model, errors)

    let model, errors = List.fold step (initial, []) [ 1..epochs ]
    (model, List.rev errors)
```

誤差は `::`（先頭への追加）で積み上げ、最後に `List.rev` で反転します。F# のリストは連結リストなので、末尾追加は O(n)、先頭追加は O(1) です。この書き方は関数型言語での定型です。

`step` の第 2 引数を `_` にしているのは、エポック番号を使わないためです。ループ回数だけが必要なら `[ 1..epochs ]` を畳み込むのが素直です。

F# は関数のデフォルト引数を持たないため、ハイパーパラメータは呼び出し側で明示します。代わりに部分適用で「設定済みの学習器」を作れます。

```fsharp
let train = linearRegression 0.01 1000 0
let model, errors = train features labels
```

## テスト

xUnit の `Assert.Equal` は第 3 引数に有効桁数を取ります。

```fsharp
[<Fact>]
let ``squareTrick の移動量は誤差に比例する`` () =
    let moved = squareTrick 0.01 { Slope = 50.0; Intercept = 100.0 } 3.0 300.0
    Assert.Equal(51.5, moved.Slope, 6)
    Assert.Equal(100.5, moved.Intercept, 6)
```

予測は `50 × 3 + 100 = 250`、誤差は 50 なので、傾きは `50 + 0.01 × 3 × 50 = 51.5` になります。

学習全体は範囲で検証します。

```fsharp
[<Fact>]
let ``linearRegression は住宅データセットに適合する`` () =
    let model, errors = linearRegression 0.01 1000 0 features labels
    Assert.InRange(model.Slope, 45.0, 55.0)
    Assert.InRange(model.Intercept, 80.0, 120.0)
    Assert.True(modelRmse model features labels < 15.0)
    Assert.Equal(1000, List.length errors)
    Assert.True(List.last errors < List.head errors)
```

## まとめ

- レコード型は追加記述なしで不変・構造的等価性を持ち、モデル表現に適しています。
- 引数の順序を「変わりにくいもの → 変わりやすいもの」にすると、部分適用で設定済みの関数を作れます。
- 学習ループは `List.fold` で、状態更新を明示的に畳み込む形に書けます。
- 誤差の蓄積は先頭追加（`::`）＋最後に `List.rev` が定型です。
