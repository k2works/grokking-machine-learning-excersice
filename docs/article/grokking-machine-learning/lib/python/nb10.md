# #10 決定木の境界を図示する（Python）

原著ノートブック: `Chapter_09_Decision_Trees/Graphical_example.ipynb`

2 次元の 12 点を決定木で分け、**決定境界を図で見る** 回です。原著は 3 つのモデルを並べます。

1. ジニ不純度で分割した木
2. エントロピーで分割した木
3. 深さ 1 に制限した木（1 本の直線になる）

原著の出力は正解率しかなく、あとは図です。
**図をそのまま再現するのは対象外** なので、
決定境界を格子上の予測ラベルとして取り出し、性質をテストにしました。

## 図をテストできる形にする

原著の `plot_model` は、格子状の点をすべて予測して塗り分けています。

```python
plot_step = 0.2
x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
xx, yy = np.meshgrid(np.arange(x_min, x_max, plot_step),
                     np.arange(y_min, y_max, plot_step))
Z = model.predict(np.c_[xx.ravel(), yy.ravel()])
Z = Z.reshape(xx.shape)
plt.contourf(xx, yy, Z, ...)
```

**`Z` が図の中身そのもの** です。`plt.contourf` に渡す直前で止めれば、
図の内容を値として扱えます。

```python
@dataclass
class DecisionGrid:
    """決定境界を格子上の予測ラベルとして持ったもの。"""

    #: x 軸の目盛
    x_values: NDArray[np.float64]
    #: y 軸の目盛
    y_values: NDArray[np.float64]
    #: 予測ラベル。`predictions[row][column]` が `(x_values[column], y_values[row])` に対応
    predictions: NDArray[np.int_]
```

格子の大きさも原著と揃えました。

```python
def test_格子は原著と同じ大きさになる() -> None:
    # x は 0 から 10 まで、y は 0 から 11 まで、刻みは 0.2。
    # arange は終端を含まないので 50 × 55 になる
    grid = decision_grid(fit())

    assert PLOT_STEP == 0.2
    assert grid.x_values[0] == pytest.approx(0.0)
    assert grid.y_values[0] == pytest.approx(0.0)
    assert grid.shape == (55, 50)
```

`np.arange` が **終端を含まない** ので、x は 0.0 から 9.8 までの 50 点になります。
`np.linspace` なら 51 点です。この違いを踏まえないと格子の大きさがずれます。

## ジニとエントロピーが同じ木になる

原著は 2 つの指標を並べて見せますが、**このデータでは同じ木になります**。

```python
def test_ジニとエントロピーは同じ木になる() -> None:
    # 分割の候補に同点が無いので、どちらの指標でも同じ順序で選ばれる。
    # #09 では同点があって木の形が変わったのと対照的
    assert split_conditions(fit()) == split_conditions(fit(criterion="entropy"))
```

```python
def test_木は3つの条件で分割する() -> None:
    # 根で x_0 <= 5.0、左で x_1 <= 8.0、右で x_1 <= 2.5
    assert split_conditions(fit()) == [
        ("x_0", 5.0),
        ("x_1", 8.0),
        ("x_1", 2.5),

```

ジニ不純度とエントロピーは値のスケールが違いますが、
**どの分割が良いかの順位はしばしば一致します**。原著が 2 つの図を並べても
同じ絵になるのは、そのためです。

## 決定木の境界は軸に平行

決定木は「ある特徴量がしきい値以下か」でしか分けられません。
つまり **境界は必ず軸に平行** で、領域は長方形の集まりになります。

これを格子から確かめました。

```python
def boundary_columns(grid: DecisionGrid) -> set[float]:
    """左右で予測が変わる x 座標を集める。

    決定木の境界は軸に平行なので、変わる位置は分割しきい値の近くに限られる。
    """
    changes: set[float] = set()
    for row in grid.predictions:
        for column in range(1, len(row)):
            if row[column] != row[column - 1]:
                changes.add(float(grid.x_values[column]))
    return changes
```

```python
def test_境界は軸に平行になる() -> None:
    # 決定木の境界は長方形の集まりなので、予測が変わる x 座標は
    # 分割しきい値の直後だけに限られる
    grid = decision_grid(fit())
    changes = sorted(boundary_columns(grid))

    # x_0 <= 5.0 の境界。刻み 0.2 の格子なので 5.0 の次の点で変わる
    assert changes == pytest.approx([5.2])
```

**横方向に予測が変わる位置は、格子全体でただ 1 か所** です。
`x_0 <= 5.0` という分割が 1 つしかないので、当然そうなります。

線形モデル（[#04](nb04.md) のパーセプトロンなど）なら、
斜めの境界になるので変わる位置は行ごとに違います。
**この 1 行のテストが、決定木と線形モデルの違いを言い当てています。**

深さ 1 の木は縦線 1 本なので、どの行も同じパターンになります。

```python
def test_深さ1の境界は縦線なので全行で同じ() -> None:
    # 1 本の縦線なので、どの行も同じパターンになる
    grid = decision_grid(fit(max_depth=1))

    assert all(np.array_equal(row, grid.predictions[0]) for row in grid.predictions)
```

深い木では `x_1` の分割が入るので、行ごとにパターンが変わります。

```python
def test_深い木の境界は行によって変わる() -> None:
    # x_1 での分割が入るので、行ごとにパターンが違う
    grid = decision_grid(fit())
    patterns = {tuple(row) for row in grid.predictions}

    assert len(patterns) > 1
```

## 深さ 1 の木は 2 点を取り違える

```python
def test_深さ1の木は12点中10点しか当てられない() -> None:
    # 直線 1 本では 2 点を取り違える
    shallow = fit(max_depth=1)

    assert shallow.score(features(), labels()) == pytest.approx(10 / 12)
```

原著は深さ 1 の木の正解率を出力していません（`plot_model` だけ呼んでいます）。
実測すると **0.8333** です。

`x_0 <= 5.0` の左側には 6 点あり、うち 1 点（`(1, 9)`, ラベル 1）が例外。
右側にも 6 点あり、うち 1 点（`(7, 1)`, ラベル 0）が例外。
**合わせて 2 点を取り違えます。**

深さを 1 増やすだけで、この 2 点が `x_1` の分割で救われて 12 点すべて正解になります。
