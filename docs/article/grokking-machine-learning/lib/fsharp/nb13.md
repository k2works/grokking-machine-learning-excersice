# #13 ニューラルネットワークの境界（F#）

原著ノートブック: `Chapter_10_Neural_Networks/Graphical_example.ipynb`

円形に分布した 110 点を、2 層の隠れ層を持つネットワークで分類し、決定境界を見ます。

**この章の発見は「重みの初期化を自分で呼ばないと学習が始まらない」こと** です。
Accord.Neuro はネットワークを作っただけでは重みが初期化されず、
何エポック回しても正解率が動きません。

## 層ごとに活性化関数を変えられない

```fsharp
let network =
    ActivationNetwork(SigmoidFunction(), 2, hiddenUnits.[0], hiddenUnits.[1], 1)
```

Accord の `ActivationNetwork` は
「活性化関数・入力数・各層のユニット数」という並びを取ります。

**活性化関数は 1 つしか渡せません。** Keras のように
「隠れ層は ReLU、出力層は softmax」と使い分けることができないのです。

原著の構成は次のようになっていました。

| 層 | 原著（Keras） | F#（Accord） |
| :--- | :--- | :--- |
| 隠れ層 1 | ReLU | シグモイド |
| Dropout | 0.2 | **無い** |
| 隠れ層 2 | ReLU | シグモイド |
| Dropout | 0.2 | **無い** |
| 出力層 | softmax（2 ユニット） | シグモイド（1 ユニット） |

`BipolarSigmoidFunction` も試しましたが、
このデータでは学習が進みませんでした（正解率 0.236 のまま）。
**選べる活性化関数が実質 1 つ** という状況です。

## 重みの初期化が必須

最初の実装は、何エポック回しても正解率 **0.2364** のままでした。
これは 26 / 110、つまり **常にクラス 1 を答えている** 値です。

学習率を変えても、ユニット数を減らしても改善しません。
原因は重みの初期化でした。

```fsharp
/// **`NguyenWidrow(...).Randomize()` が必須である。** これを呼ばないと重みが
/// 初期化されず、何エポック回しても学習が進まない（常に同じクラスを答え、
/// 正解率 0.236 のまま）。Keras は層を作った時点で自動的に初期化するので、
/// 移植のときに見落としやすい。
let fit (data: Circle) (epochs: int) (seed: int) =
    Accord.Math.Random.Generator.Seed <- System.Nullable seed

    let network =
        ActivationNetwork(SigmoidFunction(), 2, hiddenUnits.[0], hiddenUnits.[1], 1)

    // 重みの初期化。これが無いと学習が始まらない
    NguyenWidrow(network).Randomize()
    ...
```

**Keras は層を作った時点で自動的に初期化します**（Glorot uniform）。
scikit-learn も Smile も同じです。Accord だけが明示を求めます。

しかも **エラーも警告も出ません**。
「学習は走るが結果が変わらない」という、いちばん気づきにくい壊れ方です。

比較用に、初期化しない版も残しました。

```fsharp
/// 重みを初期化せずに学習する。比較用。
///
/// `NguyenWidrow` を呼ばない場合にどうなるかを示すために残してある。
let fitWithoutInitialization (data: Circle) (epochs: int) (seed: int) = ...
```

```fsharp
[<Fact>]
let ``重みを初期化しないと学習が始まらない`` () =
    // NguyenWidrow を呼ばないと、何エポック回しても常に同じクラスを答える。
    // Keras は層を作った時点で自動的に初期化するので、移植のときに見落としやすい
    let network = fitWithoutInitialization data 1000 0

    Assert.Equal(26.0 / 110.0, accuracy network data, 12)
```

**「壊れた状態」をテストで固定する** のは珍しい書き方ですが、
ここでは意味があります。将来 Accord の版が上がって自動初期化されるようになれば、
このテストが落ちて教えてくれます。

## 初期化すれば完全に分類できる

```fsharp
[<Fact>]
let ``重みを初期化すれば完全に分類できる`` () =
    // 原著（Keras・Dropout あり）は 0.88 前後。Dropout が無いぶん過学習して 1.0 になる
    Assert.Equal(1.0, accuracy (fit data Epochs 0) data, 12)
```

**正解率 1.0 です。原著の 0.88 より「良い」のですが、これは悪い知らせです。**

110 点に対してパラメータが 8770 個あります（[Python 版](../python/nb13.md) 参照）。
Dropout が無いので、ネットワークは訓練データを丸暗記できてしまいます。

原著が `Dropout(0.2)` を 2 か所に入れているのは、まさにこれを防ぐためです。
**Dropout を外すと何が起きるかが、数字で見えました。**

Kotlin（Smile）は Dropout が無くても 0.891 でした。
あちらは最適化が単純で収束が遅く、**結果的に学習しきれなかった** のです。
「最適化が弱いことが正則化の代わりになる」という、あまり褒められない状況です。

## 境界は曲線になる

```fsharp
[<Fact>]
let ``境界は閉じた形になる`` () =
    // 円形のデータなので、内側を囲む境界ができる。
    // 少なくとも 1 行は「外・内・外」と 2 回切り替わる
    let changes = boundaryChangesPerRow (decisionGrid (fit data Epochs 0) data PlotStep)

    Assert.True(List.max changes >= 2, $"changes={changes}")
```

Python・Kotlin と同じテストが通ります。

境界の抽出は `Array.pairwise` で書きました。

```fsharp
let boundaryChangesPerRow (grid: int[][]) =
    grid
    |> Array.map (fun row -> row |> Array.pairwise |> Array.filter (fun (a, b) -> a <> b) |> Array.length)
    |> List.ofArray
```

[#09](nb09.md) のしきい値候補、[#10](nb10.md) の境界探索に続いて 3 度目の `pairwise` です。
「隣り合う要素を比べる」という操作が、この連載では繰り返し出てきます。

## 3 言語の比較

| 項目 | Python（Keras） | Kotlin（Smile） | F#（Accord） |
| :--- | :--- | :--- | :--- |
| 隠れ層の活性化 | ReLU | ReLU | **シグモイドのみ** |
| 出力層 | softmax（2） | シグモイド（1） | シグモイド（1） |
| Dropout | あり | 無い | 無い |
| 最適化 | Adam | 確率的勾配降下 | 誤差逆伝播 |
| 重みの初期化 | 自動 | 自動 | **手動で呼ぶ必要あり** |
| 100 エポック後 | 0.88 | 0.764（学習せず） | 0.8 超 |
| 十分な学習後 | 0.88 | 0.891（2000 回） | **1.0**（過学習） |

**3 つとも違う理由で違う結果になりました。**
Keras は Dropout で抑え、Smile は収束が遅くて届かず、Accord は抑えるものが無くて丸暗記する。

原著の 0.88 という数字は「ちょうど良く抑えられた結果」であり、
高くも低くも外れうるものだと分かります。

## この章で F# が効いた場面・効かなかった場面

| 場面 | 評価 |
| :--- | :--- |
| 境界の抽出 | **効いた** — `Array.pairwise` で 1 行 |
| 壊れた状態の記録 | **効いた** — 初期化なし版を残してテストで固定 |
| 活性化関数 | **効かなかった** — 層ごとに変えられない |
| Dropout | **効かなかった** — 無く、過学習を抑えられない |
| 重みの初期化 | **効かなかった** — 手動で、しかも警告も出ない |
