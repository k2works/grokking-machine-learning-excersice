# 第 1 章 機械学習とは何か

原著第 1 章「What is machine learning?」を扱います。**本章にコードはありません。** 第 3 章以降で実装するものが何なのか、その全体像を先に押さえます。

各言語版はありません。概念に言語差がないためです。第 3 章から [Python 版](../python/ch03.md)・[Kotlin 版](../kotlin/ch03.md)・[F# 版](../fsharp/ch03.md) に分かれます。

## 機械学習とは「規則をデータから作る」こと

従来のプログラミングと機械学習の違いは、**何を人間が書くか** です。

| | 従来のプログラミング | 機械学習 |
| :--- | :--- | :--- |
| 人間が書くもの | **規則** | **規則の形と、良し悪しの測り方** |
| コンピュータが出すもの | 答え | **規則そのもの** |
| 入力 | データ + 規則 | データ + 正解 |
| 出力 | 答え | 規則（モデル） |

第 3 章の線形回帰で言えば、人間が書くのは次の 3 つだけです。

1. **モデルの形**: `price = slope × rooms + intercept`（直線であること）
2. **良し悪しの測り方**: 二乗誤差
3. **改善のしかた**: 誤差が減る方向へ少し動かす

`slope = 50` という具体的な値は、**データが決めます**。これが「学習」です。

## 3 つの構成要素

本シリーズで実装するアルゴリズムは、章が変わっても同じ 3 要素でできています。

| 要素 | 意味 | 例（章） |
| :--- | :--- | :--- |
| **モデル** | 予測を出す関数の形 | 直線（3 章）、多項式（4 章）、木（9 章）、ネットワーク（10 章） |
| **損失** | 予測の悪さを測る数 | 二乗誤差（3 章）、対数損失（6 章）、ヒンジ損失（11 章） |
| **最適化** | 損失を減らす手続き | 勾配降下法（3〜6・10 章）、貪欲探索（9 章）、数え上げ（8 章） |

**この 3 つの組み合わせを変えると、別のアルゴリズムになります。**

たとえば第 5 章のパーセプトロンと第 6 章のロジスティック回帰は、モデル（線形）も最適化（確率的勾配降下法）も同じで、**損失だけが違います**。それだけで挙動が大きく変わりました。

| 章 | モデル | 損失 | 最適化 |
| :--- | :--- | :--- | :--- |
| 5 | 線形 | パーセプトロン誤差 | SGD |
| 6 | 線形 | **対数損失** | SGD |
| 11 | 線形 | **ヒンジ損失** | SGD |

**3 章とも「直線を引く」ことは同じです。** 何を「悪い」とみなすかが違うだけで、第 5 章は境界線ぎりぎりの解に、第 6 章は確率の出る解に、第 11 章は余白の広い解に落ち着きました。

## 教師あり学習という枠組み

本シリーズが扱うのは、すべて **教師あり学習** です。「正解付きのデータ」から規則を学びます。

| 章 | 入力 | 正解 |
| :--- | :--- | :--- |
| 3・4 | 部屋数、年齢と収入 | 価格（**数値**） |
| 5〜7・10〜13 | 単語の出現数、座標 | クラス（**0 か 1**） |
| 8 | メールの単語 | スパムか否か |
| 9 | 性別と年齢 | 推薦するか否か |

正解が数値なら **回帰**、クラスなら **分類** です。第 3・4 章が回帰、第 5 章以降が分類にあたります。

第 2 章では、教師あり学習以外の枠組み（教師なし学習・強化学習）も見ます。

## 「学習した」と言えるのはいつか

もっとも重要な問いです。**訓練データを完璧に当てられることは、学習の証明になりません。**

第 4 章で実装する多項式回帰では、次数を上げれば訓練誤差はいくらでも下がります。しかしテストデータでの誤差は逆に悪化しました。

| 次数 | 訓練 RMSE | テスト RMSE |
| ---: | ---: | ---: |
| 1 | 0.1736 | 0.2200 |
| 5 | **0.0601** | **0.2947** |

**訓練データを丸暗記しただけの状態を「過学習」と呼びます。** これを見つけるには、学習に使わないデータを取り分けておく必要があります。

第 4 章で訓練／テスト分割を実装するのはこのためです。**「学習したかどうか」を測る仕組みそのものが、機械学習の一部です。**

## 本シリーズの方針

原著のコードは NumPy と scikit-learn を使いますが、本シリーズでは **3 言語とも ML ライブラリを使わず標準ライブラリだけで実装** します。

`model.fit(X, y)` を呼ぶだけなら 1 行ですが、その中で何が起きているかは見えません。**重みがどう動くか、誤差がどう減るかを自分の手で書く** ことが、本シリーズの目的です。

そのぶん実装は素朴になります。行列演算は最適化されていませんし、データ量が増えれば遅くなります。**教材としての読みやすさを、性能より優先しています。**
