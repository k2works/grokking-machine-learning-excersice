    #18 類似度行列で RBF カーネルを分解する（Python）¶

    原著ノートブック: Chapter_11_Support_Vector_Machines/Calculating_similarities.ipynb

    RBF カーネルの正体を 手で計算して見せる 回です。

    7 点の小さなデータに対して全対の類似度を計算し、7 列の特徴量を足してから 線形 SVM を当てます。kernel='rbf' を書かずに RBF SVM を組み立てる、 という構成そのものが説明になっています。

    この回は 数字がすべて桁まで一致 しました。乱数が絡まないからです。

    サンプル実装¶

    項目 内容
    実装 apps/grokking-ml-python-lib/src/grokking_ml_lib/nb18_calculating_similarities.py
    テスト apps/grokking-ml-python-lib/tests/test_nb18_calculating_similarities.py
    実行 uv run pytest tests/test_nb18_calculating_similarities.py

    「類似度」は RBF カーネルそのもの¶

    def similarity(x, y) -> float:
    """原著の類似度。RBF（ガウス）カーネルそのもの。

    `exp(-(x1-y1)^2 - (x2-y2)^2)` は `exp(-||x-y||^2)`、
    つまり γ = 1 の RBF カーネルである。
    同じ点なら 1、離れるほど急速に 0 に近づく。
    """
    return float(np.exp(-((x[0] - y[0]) ** 2) - (x[1] - y[1]) ** 2))

    原著はこれを「類似度」としか呼びません。しかし式を見れば exp(-||x - y||²) で、これは γ = 1 の RBF カーネルです。

    カーネルという言葉を出さずにカーネルを導入する のが、この章の狙いです。

    def test_類似度は距離の2乗で決まる() -> None:
    # exp(-||x-y||^2)。距離 1 なら exp(-1)
    assert similarity([0, 0], [1, 0]) == pytest.approx(math.exp(-1), rel=1e-15)
    # 距離 √2 なら exp(-2)
    assert similarity([0, 0], [1, 1]) == pytest.approx(math.exp(-2), rel=1e-15)
    # 原著のセルに残っている出力 1.522997974471263e-08 は (0,0) と (3,3) の類似度
    assert similarity([0, 0], [3, 3]) == pytest.approx(1.522997974471263e-08, rel=1e-15)

    最後の行は小さな発見です。原著の similarity を定義したセルに、 なぜか 1.522997974471263e-08 という出力が残っています。 定義だけのセルに出力が付くはずはないので、著者が試しに呼んだ跡 でしょう。

    exp(-18) = 1.522997974471263e-08 を逆算すると、距離の 2 乗が 18、 つまり (0, 0) と (3, 3) です。消し忘れた実験の跡から、 何を試したかが分かります。

    類似度行列は対称で、対角が 1¶

    def test_類似度は対称(data) -> None:
    matrix = similarity_matrix(data)

    assert np.allclose(matrix, matrix.T, rtol=0, atol=0)


def test_対角成分はすべて1(data) -> None:
    # 自分自身との類似度
    assert list(np.diag(similarity_matrix(data))) == [1.0] * 7

    rtol=0, atol=0 にしているのは、誤差込みではなく完全一致 を確かめたいからです。 exp(-d) は d が同じなら同じ値を返すので、対称性は厳密に成り立ちます。

    原著の表と突き合わせます。

    def test_類似度行列は原著の表と一致する(data) -> None:
    matrix = similarity_matrix(data)

    # 原著の表の 1 行目: 1.000000 0.367879 0.367879 0.367879 0.367879 0.135335 ...
    assert matrix[0][1] == pytest.approx(0.36787944117144233, rel=1e-15)
    assert matrix[0][5] == pytest.approx(0.1353352832366127, rel=1e-15)
    # 2 行目の Sim4: 0.018316（距離の 2 乗が 4）
    assert matrix[1][4] == pytest.approx(0.01831563888873418, rel=1e-15)
    # 3 行目の Sim5: 0.006738（距離の 2 乗が 5）
    assert matrix[2][5] == pytest.approx(0.006737946999085467, rel=1e-15)

    値は 5 種類しかありません（exp(0)・exp(-1)・exp(-2)・exp(-4)・exp(-5)）。 7 点が格子上に並んでいるので、距離の 2 乗が整数になるからです。 題材の選び方が上手い ところです。

    線形カーネルで RBF SVM を作る¶

    def fit(data: pd.DataFrame) -> SVC:
    """**線形** SVM を、類似度を足した特徴量に当てる。

    `kernel='rbf'` を指定していないのが要点である。
    カーネルは既に特徴量として展開済みなので、線形で足りる。
    """
    model = SVC(kernel="linear")
    model.fit(features(data), data["y"])
    return model

    def test_線形カーネルを使っている(data) -> None:
    # カーネルは特徴量として展開済みなので、SVM 側は線形でよい
    assert fit(data).kernel == "linear"

    これがこの章の核心です。カーネルトリックとは、 「高次元に写した特徴量で線形分離する」ことの計算上の近道 にすぎません。 7 点しかなければ、写した特徴量を素直に作ってしまえます。

    係数まで一致する¶

    def test_SVMの係数は原著と一致する(data) -> None:
    # 原著の svm.coef_
    #   [ 0.67476187, 0.67482825, -1.09720887, -0.64636729, -0.64708568,
    #     0.01538266, 0.01603589, 0.67770347, 0.6776795 ]
    expected = [
        0.67476187,
        0.67482825,
        -1.09720887,
        -0.64636729,
        -0.64708568,
        0.01538266,
        0.01603589,
        0.67770347,
        0.6776795,
    ]

    assert list(fit(data).coef_[0]) == pytest.approx(expected, abs=5e-9)

    原著が印刷した 8 桁すべてが一致しました。

    原著の実行時（SVC の repr に break_ties が出ている版なので scikit-learn 0.22 頃）と 現在の 1.9 で、libsvm の解が変わっていないということです。

    このシリーズで係数まで一致したのは #02 以来です。 SVM は凸最適化なので 解が一意に決まる ためで、 ニューラルネットワークのように初期値で変わることがありません。

    手書きの予測式¶

    原著は最後に、SVM の係数を使わない予測式を手で書きます。

    def svm_rbf_prediction(data: pd.DataFrame, new_point) -> float:
    """原著が手で書いた予測式。

    学習した SVM の係数ではなく、**ラベルの符号をそのまま重みにする**。
    `similarity` の重み付き和が正なら 1、負なら 0 と読む。
    """
    points = data[["x1", "x2"]].to_numpy(dtype=float)
    similarities = [similarity(new_point, point) for point in points]
    return float(np.dot(similarities, PREDICTION_SIGNS))

    重みは [-1, -1, -1, 1, 1, 1, 1]、つまり ラベルをそのまま符号にしただけ です。 学習していません。

    def test_手書きの予測式は原著と桁まで一致する(data) -> None:
    # 原著の出力をそのまま並べたもの
    expected = [
        -0.7293294335267746,
        -0.9749464141121803,
        -0.9749464141121804,
        0.9884223081103513,
        0.9884223081103514,
        0.8650001793912898,
        0.8650001793912898,
    ]

    assert training_predictions(data) == pytest.approx(expected, rel=1e-15)

    16 桁すべて一致します。 exp と加算しかしていないので当然ですが、 原著の出力をそのまま貼れる回は貴重です。

    面白いのは、この「学習していない予測器」でも 7 点すべてを正しく分類することです。

    def test_予測の符号は正解ラベルと合う(data) -> None:
    # 原著のコメント「ラベルが 1 なら正、0 なら負になるはず」
    for value, label in zip(training_predictions(data), data["y"], strict=True):
        assert (value > 0) == (label == 1)

    これは k 近傍法に近い考え方です。 「近くにある点のラベルの多数決を、距離で重み付けする」 と読めます。 RBF SVM の予測式も本質的にはこの形（重みが学習で決まるだけ）です。

    RBF は遠くを見ない¶

    def test_遠く離れた点の予測は0に近づく(data) -> None:
    # RBF は距離とともに指数的に減る。データから離れると判断できなくなる
    assert abs(svm_rbf_prediction(data, [10, 10])) < 1e-30

    (10, 10) での予測値は 1e-30 を下回ります。実質 0 です。

    RBF カーネルは局所的で、データから離れた場所については何も言えません。 線形モデルなら遠くまで外挿しますが、RBF は「知らないところは 0」と答えます。 どちらが良いかは場合によりますが、外挿しないことは安全側の性質 です。

    まとめ¶

    項目 原著と一致するか
    7 点のデータ 完全一致
    類似度行列 16 桁まで一致
    SVM の係数 9 個 原著が印刷した 8 桁すべて一致
    手書きの予測式の 7 つの値 16 桁まで一致
    境界の図 描かない
